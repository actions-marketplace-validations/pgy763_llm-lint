text/event-stream 不带 charset，Spring 按默认编码把 String 写出去，中文在浏览器里是问号，接口却是 200。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM006`。

## 为什么会踩

**搜这些能找到这条：** `中文变成 ???`、`SSE 接口 200，只有汉字是坏的`

```java
// 会报
@GetMapping(value = "/chat", produces = "text/event-stream")
```

改法：`produces = "text/event-stream;charset=UTF-8"`，或 `MediaType.TEXT_EVENT_STREAM_VALUE + ";charset=UTF-8"`。

这条有现成补丁：`llm-lint --fix src` 会输出把 charset 补上的 unified diff，`git apply` 即可。
