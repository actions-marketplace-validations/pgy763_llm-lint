## LLM018 流式接口没声明 produces

| 项 | 值 |
| --- | --- |
| 级别 | warning |
| 框架 | 通用 |
| 自动修正 | 有现成补丁：`--fix`（`--fix --write` 直接改） |

返回 Flux 但没写 produces，Spring 会按 Jackson 的 JSON 走：先收完整个流再一次性写出去，代理也更容易把响应攒着——流式就白开了。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM018`。

## 为什么会踩

**搜这些能找到这条：** `流式接口没写 produces`、`前端等很久，最后一次性全出来`

```java
// 会报
@GetMapping("/tickets/stream")
public Flux<String> stream() {
    return Flux.just("a", "b");
}
```

改法：`@GetMapping(value = "/tickets/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)`。

这条有现成补丁：`llm-lint --fix src` 会输出加上 `produces` 的 unified diff（字符串字面量，不用补 import），`git apply` 即可。
