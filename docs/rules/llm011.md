## LLM011 每次请求都新建 ChatClient/ChatModel

| 项 | 值 |
| --- | --- |
| 级别 | error |

| 自动修正 | 没有现成补丁，按下面的改法手工改 |

Spring AI 的 ChatClient/ChatModel 与 LangChain4j 的 ChatLanguageModel 都是「建一次、随便用」的东西：内部带连接池和重试器。在业务方法里建，等于每个请求重开连接池、重做 TLS 握手，并发一高线程和端口先耗尽。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM011`。

## 为什么会踩

**搜这些能找到这条：** `连接池反复重建、端口耗尽`、`每个请求都 new 一个 ChatClient`


```java
// 会报
public String answer(String question) {
    ChatClient client = ChatClient.create(chatModel);
    return client.prompt().user(question).call().content();
}
```

改法：在 `@Bean` 方法里建一次，业务类注入复用。

判断范围：非 `@Bean` 的方法里，以客户端类型名（`ChatClient`、`ChatModel`、`ChatLanguageModel`、
`EmbeddingModel` 等）为接收者的 `create(...)` 或 `builder()` 调用。`AiServices` 归 LLM012。
