## LLM002 单例里共用一份 ChatMemory

| 项 | 值 |
| --- | --- |
| 级别 | error |
| 框架 | 通用 |
| 自动修正 | 没有现成补丁，按下面的改法手工改 |
| 更多 | https://pgy763.github.io/llm-dev-pitfalls/java/多用户共用一份ChatMemory |
| 关掉它 | .llm-lint.yml 里写 `LLM002: off`，或命令行 `--disable LLM002` |

ChatMemory 里装的是对话。单例 Bean 只 new 一份，所有用户往里写，A 的提问就成了 B 的上下文——这类串话在压测里看不出来。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM002`。

## 为什么会踩

**搜这些能找到这条：** `用户 A 的名字出现在用户 B 的对话里`、`ChatMemory 串台`

```java
// 会报
@Service
public class ChatService {
    private final ChatMemory chatMemory = MessageWindowChatMemory.withMaxMessages(20);
}
```

改法：按会话 id 从 `ChatMemoryProvider` / `ChatMemoryStore` 取，或者用 `MessageChatMemoryAdvisor` 按会话隔离。

判断范围：`@Service` / `@Component` / `@Repository` / `@Controller` 这类单例 Bean 里，字段或构造参数的类型以 `ChatMemory` / `ChatMemoryStore` 结尾。
