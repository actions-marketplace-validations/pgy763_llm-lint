## LLM010 硬编码的 API key

| 项 | 值 |
| --- | --- |
| 级别 | error |
| 框架 | 通用 |
| 自动修正 | 没有现成补丁，按下面的改法手工改 |
| 更多 | https://pgy763.github.io/llm-dev-pitfalls/auth/密钥提交进了git历史 |
| 关掉它 | .llm-lint.yml 里写 `LLM010: off`，或命令行 `--disable LLM010` |

密钥一旦提交进 git 就永远在历史里。删掉那一行不够——clone 和 fork 都还带着它，只能先吊销再换。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM010`。

## 为什么会踩

**搜这些能找到这条：** `sk-...`、`AIza...`


```java
// 会报
private static final String API_KEY = "sk-proj-AbCdEf0123456789";
```

改法：`System.getenv("LLM_API_KEY")` 或配置中心。已经提交过的，先吊销再换——删掉那一行不够。

判断范围：字符串字面量里出现 `sk-` / `sk-proj-` / `sk-ant-` / `AIza` / `hf_`，且不含 `${`
和 `***`（占位符不报）。
