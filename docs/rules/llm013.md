## LLM013 循环里逐个调模型/向量库

模型和向量库的耗时几乎全在网络往返上。循环里一次一条，10 条就是 10 次 RTT，延迟线性叠加，而批量接口往往能一次带走。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM013`。

## 为什么会踩

**搜这些能找到这条：** `N 条数据要 N 倍时间`、`循环里逐个调模型`

```java
// 会报
for (String text : texts) {
    vectors.add(embeddingModel.embed(text));
}
```

改法：能批量的一次带走（`embedAll(texts)`、一次查多个 id）；实在要逐条的，至少并发发出去再一起等。

判断范围：`call` / `chat` / `generate` / `generateStream` / `stream` / `similaritySearch` / `search` / `embed` / `embedAll` / `embedForResponse` / `retrieve`，接收者是模型或向量库类型，且调用出现在 `for` / `for-each` / `while` / `do` 里，或者 `forEach` / `map` 这类流操作符的 lambda 里。
