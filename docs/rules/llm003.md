## LLM003 让容器注入 ChatClient

| 项 | 值 |

Spring AI 的自动配置只注册 ChatClient.Builder 和 ChatModel，没有 ChatClient 这种 Bean。注入它启动就失败，报的还只是「找不到 Bean」。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM003`。

## 为什么会踩

**搜这些能找到这条：** `NoSuchBeanDefinitionException: No qualifying bean of type 'ChatClient'`、`启动就挂，找不到 ChatClient`

```java
// 会报：启动就是 NoSuchBeanDefinitionException
@Autowired
private ChatClient chatClient;
```

改法：注入 `ChatClient.Builder`，在构造里 `build()`；或者自己定义一个 `@Bean ChatClient`。

判断范围：字段或构造参数类型以 `ChatClient` 结尾，且带 `@Autowired` / `@Resource` / `@Inject`，或者出现在构造器参数里。自己 `build()` 出来的字段不报。
