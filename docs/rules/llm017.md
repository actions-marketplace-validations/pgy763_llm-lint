## LLM017 事务里查/写向量库

| 项 | 值 |
| --- | --- |
| 级别 | error |
| 框架 | 通用 |
| 自动修正 | 没有现成补丁，按下面的改法手工改 |

向量的写入和检索都要先算嵌入、再走一次网络：事务里等这几百毫秒，数据库连接一直被这个线程占着，并发一上来先报「拿不到连接」。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM017`。

## 为什么会踩

**搜这些能找到这条：** `事务里 vectorStore.add 之后连接池超时`、`RAG 写入拖垮连接池`


```java
// 会报
@Transactional
public void ingest(String title, String body) {
    vectorStore.add(List.of(new Document(body)));
}
```

改法：向量写入/检索挪到事务外面，事务只包住数据库那一段。
