catch 里什么都不做，等于把「写失败」当成「写成功」。连接断了也看不出来，日志干净，用户那头停在半句。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM008`。

## 为什么会踩

**搜这些能找到这条：** `客户端断开之后 token 还在烧`、`写流时的 IOException 被 catch 吞了`

```java
// 会报
try {
    emitter.send(SseEmitter.event().data(chunk));
} catch (IOException e) {
    // 客户端断了？不管它
}
```

改法：捕获后 `emitter.complete()` 并 `return`——连接已经没了，继续写只是白烧 token。

判断范围：`catch` 的参数是 `IOException` / `Exception` / `Throwable`，catch 体为空，且 `try` 里有 `write` / `send` / `flush` / `flushBuffer` / `writeAndFlush`。
