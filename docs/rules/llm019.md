## LLM019 工具方法里做阻塞调用

| 项 | 值 |

| 框架 | 通用 |
| 自动修正 | 没有现成补丁，按下面的改法手工改 |

工具调用跑在请求线程上。方法里查一次库、调一次同步接口、甚至睡一会儿，模型那边都在等：看起来是「模型变慢了」，其实是它在等你的工具。该查的东西先查好再交给工具，或者让工具返回一句「正在处理」由后台去做。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM019`。

## 为什么会踩

**搜这些能找到这条：** `工具调用很慢`、`@Tool 里查数据库`、`模型一直在等工具`

```java
// 会报
@Tool("查订单现在到哪了")
public String orderStatus(String orderId) {
    return orderRepository.findById(orderId).status();
}
```

改法：查库、调同步接口、`Thread.sleep` 这些挪到调用工具之前，或者让工具只读已经准备好的数据；确实要慢活的，让工具先返回一句「正在处理」，把活交给后台。

判断范围：方法带 `@Tool`，方法体里出现 `.block()` / `.blockFirst()` / `.blockLast()` / `.join()`、`Thread.sleep(`、Future 上的 `.get()`，或者调用接收者类型名以 `Repository` / `Mapper` / `JdbcTemplate` / `RestTemplate` / `WebClient` 结尾。只读 `Map`、缓存、静态工具类的调用不算。
