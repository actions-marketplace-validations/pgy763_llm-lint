## LLM012 每次请求都新建 AiServices

| 项 | 值 |
| --- | --- |
| 级别 | error |
| 框架 | LangChain4j |
| 自动修正 | 没有现成补丁，按下面的改法手工改 |
| 更多 | https://github.com/pgy763/llm-lint/blob/main/docs/rules.md#llm012 |

AiServices.create(...) 会把 memory、ContentRetriever、tools 绑到生成的代理上。放在业务方法里，等于每个请求一份新记忆——上一句说的话下一句就忘，检索器和工具也要重新装配。代理本身线程安全，建一次就够。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM012`。

## 为什么会踩

**搜这些能找到这条：** `启动慢、内存涨`、`每个请求都重建 AiServices`


```java
// 会报
public Assistant assistant() {
    return AiServices.create(Assistant.class, model);
}
```

改法：在 `@Bean` 里建一个单例 `AiServices`，记忆按会话 id 从 `ChatMemoryProvider` 取。
