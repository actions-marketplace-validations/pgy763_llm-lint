## LLM014 ChatMemoryProvider 用了写死的 id

| 项 | 值 |
| --- | --- |
| 级别 | error |
| 框架 | LangChain4j |
| 自动修正 | 没有现成补丁，按下面的改法手工改 |
| 更多 | https://pgy763.github.io/llm-dev-pitfalls/java/多用户共用一份ChatMemory |
| 关掉它 | .llm-lint.yml 里写 `LLM014: off`，或命令行 `--disable LLM014` |

ChatMemoryProvider 是按 id 发记忆的，id 写死就等于全站一个会话：A 说过的名字、地址会出现在 B 的上下文里。这类问题在压测里看不出来，上线后第一个投诉的是用户。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM014`。

## 为什么会踩

**搜这些能找到这条：** `所有人共用一份记忆`、`conversationId 写死`

```java
// 会报
public ChatMemory memoryFor(String userId) {
    return memoryProvider.get("default");
}
```

改法：id 从请求里来（会话 id / userId），每个会话一条，用完按 TTL 清。
