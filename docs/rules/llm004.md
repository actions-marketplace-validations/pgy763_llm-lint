new SseEmitter() 用的是容器默认超时（Tomcat 30 秒）。模型还没生成完，连接先被掐了，前端看到的是「回答到一半停住」。

只想在某一处放过它：在该行或上一行写 `// llm-lint:ignore LLM004`。

## 为什么会踩

**搜这些能找到这条：** `AsyncRequestTimeoutException`、`流式回答到三十秒就断`

```java
// 会报
@GetMapping(value = "/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter stream(String q) {
    SseEmitter emitter = new SseEmitter();
    ...
}
```

改法：`new SseEmitter(180_000L)`——按最长的一条回答给，别用默认值；真要无限就显式传 `0`，并且配上 `onTimeout` 收尾。
